# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. One frame, one box, one name. Then the stake: Car is 59% of every frame. Will it still see a bus?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the race: Majority class 58.7%, Notebook CNN 64.5%, MobileNetV2 + two heads 73.0%; MobileNetV2 + two heads wins, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Detect: bus, one hundred percent, boxed A second frame, or drop your own Tesla sheet: claimed 35, verified 16
4. **The answer** (68 to 90 s): 73.0%, val accuracy · 900 held-out frames · baseline 58.7%. Notebook 64.5 → 73.0 here. And it ships. One limit: One box per frame. IoU 0.25: boxes are loose. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
